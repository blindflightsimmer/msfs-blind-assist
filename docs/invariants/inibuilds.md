# iniBuilds A330 / A321LR (MSFS 2024) — rules in full

Each section is the complete text of one rule. Its one-line form, under the same ID, is in `.claude/rules/inibuilds.md`, which Claude Code loads when it reads matching code. Background: [ini-a330.md](../ini-a330.md) and [ini-a321.md](../ini-a321.md).

## INI-1

- The A330's controls are FS2024 INPUT EVENTS (`B:AIRLINER_*`), not writable L:vars. Selectors and latching switches take `SetInputEvent` with the POSITION as the value; momentary keys work ONLY through the calculator `(>B:NAME_Push)` / `(>B:NAME_Release)` — `SetInputEvent` 1 then 0 does nothing on them. Measured conventions: a push-button's input 0 = ON, a 3-position switch's 0 = top, a 2-position switch's 1 = top. Always translate a picked position through `A330ControlMap.InputFor`; never send back the value that was read. → [ini-a330.md](../ini-a330.md)

## INI-2

- `Resources/a330_control_map.json` is GENERATED by `tools/a330-gen` from the aircraft's own input-event catalogue, and `Resources/a321_control_map.json` by `tools/a321-gen` (the A330 map re-pointed to the A321's direct L:var writes and validated against the A321's L:var list). Regenerate; never hand-edit either. → [ini-a330.md](../ini-a330.md), [ini-a321.md](../ini-a321.md)

## INI-4

- Neither MCDU exports text an external app can read, so both are READ FROM PIXELS by the trained fixed-font matcher (`A300CduScreenReader`, named after the iniBuilds A300 where the technique was first built), each with its own `CduPopoutProfile` (instrument views, aspect, window size) and `CduLayout` (grid, letter height, ink threshold). The pop-out uses a DARK-GLASS screen finder (a green-cluster finder fails on the mostly white/grey MCDU MENU page), waits for the camera to settle, and brings the sim forward with a four-step foreground chain ending in WScript `AppActivate`, because an FS2024 window refuses the plain `SetForegroundWindow` from a background process. The ink threshold is 40, because these MCDUs draw unavailable options in GREY that peaks near 77. `CduLayout.BaseCap` must equal the trainer's `BASE_CAP` (a test pins it): 18.5 against 18.3 scaled every glyph 1 % off its templates and misread letters. Retrain with `tools/a330-cdu-ocr` / `tools/a321-cdu-ocr`; never patch the glyph `.bin` files. → [ini-a330.md](../ini-a330.md)

## INI-5

- `IniA321Definition` SUBCLASSES `IniA330Definition` (one iniBuilds code base: the same L:var names for most systems and the same autoflight). Everything that differs goes through the A330 definition's virtual hooks (`Ev`, `Buttons`, `SelectKeys`, `Detents`, `Tanks`, `SpeedLvars`, the view indices, `CduProfile`, `CreateEfbClient`, `SetOwnEvent`, `SetAutobrake`, and the rest). Never fork the A330 code for the A321, and keep every hook's default exactly the A330's behaviour — `The_A330_definition_is_unchanged_by_the_hooks` pins it. → [ini-a321.md](../ini-a321.md)

## INI-6

- The A321's FS2024 input events do NOTHING when driven from outside (set by value or through `_Push` — probed), so its controls are the `INI_*` L:vars, written directly. The one exception is the FCU knob pulls/pushes (`INSTRUMENT_FCU_*`, a value press). A held write is not proof that a control works: judge it by what moved DOWNSTREAM. The single `INI_LANDING_LIGHT_SWITCH` and the `…_PB_IS_AUTO` battery twins hold a write and drive nothing (or revert); the real ones are `A320_LANDING_LIGHT_SWITCH_LEFT/RIGHT` (0 = ON) and `…_PB_IS_AUTO_SWITCH`. → [ini-a321.md](../ini-a321.md)

## INI-7

- MCDU CLR is the `CLR` key (`INI_MCDU1_CLR`); NEVER write `INI_MCDU1_CLR_KEY`, which is a HELD state that wipes everything typed while it stays 1. `CduLayout.TinyMarksJoinRuns` is A321-only: the A330 library was trained without it, and turning it on there changes how that library's runs are split. → [ini-a321.md](../ini-a321.md)

## INI-8

- Never confuse the iniBuilds A330 (`IniA330Definition`, FS2024 built-in, input events + pixel-read MCDU) with the LatinVFR A330 (LvfrA330Definition, Coherent-scraped MCDU, L:vars and H events) — different aircraft, different transport. → [ini-a330.md](../ini-a330.md)
