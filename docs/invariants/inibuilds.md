# iniBuilds A330 (MSFS 2024) — rules in full

Each section is the complete text of one rule. Its one-line form, under the same ID, is in `.claude/rules/inibuilds.md`, which Claude Code loads when it reads matching code. Background: [ini-a330.md](../ini-a330.md).

## INI-1

- The A330's controls are FS2024 INPUT EVENTS (`B:AIRLINER_*`), not writable L:vars. Selectors and latching switches take `SetInputEvent` with the POSITION as the value; momentary keys work ONLY through the calculator `(>B:NAME_Push)` / `(>B:NAME_Release)` — `SetInputEvent` 1 then 0 does nothing on them. Measured conventions: a push-button's input 0 = ON, a 3-position switch's 0 = top, a 2-position switch's 1 = top. Always translate a picked position through `A330ControlMap.InputFor`; never send back the value that was read. → [ini-a330.md](../ini-a330.md)

## INI-2

- `Resources/a330_control_map.json` is GENERATED by `tools/a330-gen` from the aircraft's own input-event catalogue. Regenerate; never hand-edit it. The generator's `SECTIONS` list is also the ONE place the cockpit's section and panel order lives (the definition's own FCU, flight-mode, flap, gear and brake panels included, as `OWN_PANELS`); it follows the app's other Airbus aircraft (FlyByWire A32NX, Fenix): overhead, glareshield, main instrument panel, pedestal. → [ini-a330.md](../ini-a330.md)

## INI-4

- The MCDU exports no text an external app can read, so it is READ FROM PIXELS by a trained fixed-font matcher (`A330CduScreenReader`) with its `CduPopoutProfile` (instrument views, aspect, window size) and `CduLayout` (grid, letter height, ink threshold). The pop-out finds the screen as DARK GLASS (a text-colour search fails on the mostly white/grey MCDU MENU page), waits for the camera to settle, and brings the sim forward with a four-step foreground chain ending in WScript `AppActivate`, because an FS2024 window refuses the plain `SetForegroundWindow` from a background process. The ink threshold is 40, because the MCDU draws unavailable options in GREY that peaks near 77. `CduLayout.BaseCap` must equal the trainer's `BASE_CAP` (a test pins it): 18.5 against 18.3 scaled every glyph 1 % off its templates and misread letters. Retrain with `tools/a330-cdu-ocr`; never patch the glyph `.bin` file. → [ini-a330.md](../ini-a330.md)

## INI-7

- Never write `INI_MCDU1_CLR_KEY`: on iniBuilds' MCDUs it is a HELD state that wipes everything typed while it stays 1. MCDU CLR is the `CLR` key (`INI_MCDU1_CLR`, a press flag the module consumes). → [ini-a330.md](../ini-a330.md)

## INI-8

- Never confuse the iniBuilds A330 (`IniA330Definition`, FS2024 built-in, input events + pixel-read MCDU) with the Headwind A330-900neo (HeadwindA330Definition, a FlyByWire A32NX-based aircraft with the A32NX's L:vars and MCDU) — different aircraft, different transport. → [ini-a330.md](../ini-a330.md)
