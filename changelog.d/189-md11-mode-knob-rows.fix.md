MD-11: the Heading/Track, IAS/MACH and VS/FPA rows on the Flight Control Panel and the minimums rows on the EFIS panels now read the current setting instead of offering a pick list — picking from the mode rows used to spin the heading, speed or vertical-speed value, and picking from the minimums rows could silently zero the minimums. Switch modes with the Heading/Track Select, IAS/MACH Select and VS/FPA Select buttons and the Minimums Mode switch beside them.
